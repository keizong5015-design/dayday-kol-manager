1
建立 Supabase 資料庫

1-1 建立帳號與專案

  1. 前往 https://supabase.com → 點 Start your project
  2. 用 GitHub 帳號登入（免費，不需信用卡）
  3. 點 New project
  4. 填入：
    • Project name：kol-manager
    • Database Password：設一個強密碼（記住它）
    • Region：選 Northeast Asia (Tokyo)（台灣最近最快）
  5. 點 Create new project，等待約 1–2 分鐘

1-2 建立資料表（執行 SQL）

  1. 左側選單點 SQL Editor
  2. 點 + New query
  3. 複製以下 SQL，貼進去後點 Run ▶️
-- 建立網紅資料表
CREATE TABLE influencers (
  id              UUID         DEFAULT gen_random_uuid() PRIMARY KEY,
  name            TEXT         NOT NULL,
  photo_url       TEXT,
  platforms       TEXT[]       DEFAULT '{}',
  styles          TEXT[]       DEFAULT '{}',
  followers_ig    BIGINT       DEFAULT 0,
  followers_yt    BIGINT       DEFAULT 0,
  followers_tiktok BIGINT      DEFAULT 0,
  engagement_rate DECIMAL(5,2) DEFAULT 0,
  status          TEXT         DEFAULT '洽談中',
  contact         TEXT,
  fee_ntd         INTEGER      DEFAULT 0,
  brand_value     TEXT,
  note            TEXT,
  created_at      TIMESTAMPTZ  DEFAULT NOW(),
  updated_at      TIMESTAMPTZ  DEFAULT NOW()
);

-- 啟用 Row Level Security
ALTER TABLE influencers ENABLE ROW LEVEL SECURITY;

-- 允許所有人公開讀取
CREATE POLICY "public_read" ON influencers
  FOR SELECT USING (true);

-- 允許寫入（前端密碼已保護管理功能）
CREATE POLICY "anon_write" ON influencers
  FOR ALL USING (true) WITH CHECK (true);
✅ 看到 Success. No rows returned 代表執行成功

2
上傳程式碼到 GitHub

2-1 建立 GitHub 帳號（已有可跳過）

前往 https://github.com 免費註冊

2-2 建立新倉庫

  1. 點右上角 + → New repository
  2. Repository name：kol-manager
  3. 選 Private（私有，保護公司資料）
  4. 點 Create repository

2-3 上傳專案檔案（最簡單方式）

  1. 在 GitHub 新建倉庫頁面，點 uploading an existing file
  2. 把整個 kol-manager 資料夾的內容拖曳進去
⚠️ 注意事項：
  • 要上傳資料夾「內部的所有檔案」，不是資料夾本身
  • 需要包含：package.json、vite.config.js、index.html、src/ 整個資料夾
  • 不要上傳 .env 檔（裡面有機密資訊）
  1. 等上傳完成後，點 Commit changes
✅ 看到所有檔案出現在 GitHub 頁面代表成功
3
部署到 Vercel（取得固定網址）

3-1 建立 Vercel 帳號

  1. 前往 https://vercel.com
  2. 點 Start Deploying → 選 Continue with GitHub
  3. 授權 Vercel 存取你的 GitHub 帳號

3-2 匯入專案

  1. 點 Add New → Project
  2. 找到 kol-manager 倉庫 → 點 Import
  3. Framework Preset 選 Vite（通常會自動偵測）
  4. ⛔ 先不要點 Deploy，先設定環境變數

3-3 設定環境變數（🔑 最重要步驟）

在 Deploy 頁面展開 Environment Variables，新增以下三個：

Name（名稱）Value（值）
VITE_SUPABASE_URL 你在 Step 1-3 複製的 Project URL
VITE_SUPABASE_ANON_KEY 你在 Step 1-3 複製的 anon public key
VITE_ADMIN_PASSWORD 自訂管理員密碼（例：Dayday@2024）
💡 每填完一個要點 Add 確認，三個都加好才繼續

3-4 正式部署

  1. 點 Deploy 按鈕
  2. 等待約 1–2 分鐘
  3. 看到 🎉 Congratulations! 代表成功
  4. Vercel 會給你一個永久網址，例如：https://kol-manager-xxx.vercel.app
✅ 這個網址就是你的固定系統入口，永不消失
4
驗證系統運作
  1. 打開你的 Vercel 網址
  2. 點右上角 ⚙️ 管理後台
  3. 輸入你在 Step 3-3 設定的管理員密碼
  4. 點 ＋ 新增網紅，填入資料並儲存
  5. 回到 🖼️ 網紅名單，確認資料出現在 Gallery 中
5
分享給同仁

直接把 Vercel 網址傳給同仁即可。

❓ 常見問題

Q：網頁打開是空白的？

→ 按 F12 開啟瀏覽器開發者工具 → Console 頁籤，看錯誤訊息。通常是環境變數沒設好。到 Vercel → 你的專案 → Settings → Environment Variables 確認三個變數都有填。

Q：新增資料後重新整理就消失？

→ Supabase 連線有問題。確認 VITE_SUPABASE_URL 和 VITE_SUPABASE_ANON_KEY 正確，且 Step 1-2 的 SQL 有成功執行。

Q：管理員密碼忘記了？

→ 到 Vercel → 你的專案 → Settings → Environment Variables，找到 VITE_ADMIN_PASSWORD 修改後重新部署。

Q：想用自訂網域（例如 kol.dayday.com）？

→ Vercel → Settings → Domains，輸入你的網域並照指示設定 DNS。
